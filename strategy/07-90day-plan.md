# 90日プラン（トラックD）

**前提の正直な補正**: トラックDで**90日以内に月10万は届きにくい**（集客の立ち上がりに2〜4ヶ月かかるため）。
90日のゴールは「**資産（ツール・リスト・実践値ログ・初期有料メンバー）を build し、初収益を出す**」。
月10万は**4〜6ヶ月目が現実的なライン**。ここを誤魔化さないのが長期の勝ち筋。

稼働時間の目安: 週10〜14h。配分は「発信4h / 制作4h / 稼働＆ログ4h」。

---

## Month 1｜基盤構築（無収入前提）
**目標**: 発信開始・ツールv1公開・LINE構築・実践値ログ開始

- W1: ブランド名決定 → X/Threadsアカウント開設 → 楔（兼業/時給）でプロフ設計。`04`のv1ツール着手。
- W2: 時給期待値ツールv1を Vercel に公開。Threads投稿を毎日（`05`のA/Bを軸に）。
- W3: LINE公式開設＋登録特典（狙い目まとめPDF・立ち回りテンプレ）。ツールにLINE CTA設置。
- W4: ステップ配信7通を実装（`06`）。自分の稼働ログ公開を開始（Cカテゴリ投稿）。
- 月末KPI: フォロワー初期母数、LINE登録の初動、ツール利用数。**収益0でOK**。

## Month 2｜集客とコンテンツ量産
**目標**: 流入チャネルを増やし、リストを積む

- 投稿を1日2〜3本に。伸びた型を分析して横展開（`05`の量産システム）。
- note単発（機種別実践値まとめ）を2〜4本 → 検索/SNS流入 → LINEへ送客。
- ツールv2（機種別狙い目まとめ）公開。可能ならv3（稼働ログ）着手。
- **βメンバー募集**（無料 or 割引）で少人数コミュニティを立ち上げ、生の声で商品を磨く。
- 月末KPI: LINE登録数の伸び、note流入、βメンバーの反応（ここが層2成立の検証）。

## Month 3｜収益化ローンチ
**目標**: 有料メンバーシップ正式開始・初の継続収益

- メンバーシップ正式ローンチ（松竹梅 ¥980／¥1,980／¥4,980・竹軸）。ステップ配信7通目のオファーを稼働。
- 実践値ログ（自分＋βメンバー）を"入る理由"として提示。
- 転換施策: 期間限定の初月特典、既存note購入者へ案内。**煽らず正直に**。
- 月末KPI: **有料メンバー 10〜30人（月1.5万〜5万目安）**、解約率、転換率。

## 撤退・軌道修正の基準（サンクコストで溺れない）
- 90日でLINE登録が伸びず（<100）、βメンバーの反応も薄い → **楔かチャネルを変える**（機種特化 or フォーマット変更）。
- それでも90日追加で兆しがなければ、**トラックA（smcn）へキャッシュ源を切替**し、Dは縮小継続。
- 記事の「先行者が逃げ切る」は本当だが、**逃げ切れるのは"続けた人"だけ**。撤退基準を先に決めておくのが継続のコツ。
