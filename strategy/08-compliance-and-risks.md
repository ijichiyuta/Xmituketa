# コンプラ＆リスク管理（トラックD｜必読）

ギャンブル隣接ジャンルで有料商品を売るため、ここを外すと**アカBAN・決済停止・行政指導**のリスク。攻めより先に守りを固める。

> 免責: 以下は一般的な整理であり法的助言ではない。有料販売・規約判断は必要に応じ専門家（税理士・弁護士）に確認を。

## 1. 景品表示法（最重要・表現規制）
- **NG表現**: 「絶対勝てる」「必ず月収○万」「誰でも稼げる」「100%」など断定・誇大。
- 体験談・実績も、平均的でない結果を"誰でも得られる"かのように見せると**優良誤認**リスク。
- **OKの型**: 「期待値を積む作業を効率化する」「長期・試行回数前提」「結果は保証しない」。打消し表示（リスク明記）をセットに。
- → `05`投稿・`06`LINE・LP、全コピーをこの基準でセルフチェック。

## 2. 特定商取引法（有料販売の義務）
- 独自決済（Stripe等）で売るなら**特商法表記が必須**（販売者名・住所・連絡先・価格・返金/解約条件）。個人でも表示義務あり（一部は請求対応で代替可）。
- note/YouTubeメンバーシップ経由なら各プラットフォームが枠組みを持つ → **まずはこちらが安全**。

## 3. プラットフォーム規約・決済
- X / Threads / note / YouTube / Stripe / App Store は**ギャンブル・射幸性関連ポリシー**を持つ。アフィリや決済で制限・停止がありうる。
- 対策: **決済経路を分散**（note ＋ YouTubeメンバー ＋ 独自Stripe）。1本足打法にしない。
- 事前確認: 各サービスの利用規約で「パチンコ・パチスロ情報販売」が禁止/制限対象か必ずチェック。

## 4. 年齢・依存症配慮
- **20歳未満お断り**を明記。
- 過度に射幸心を煽らない。資金管理・やめどき・依存症配慮の発信を混ぜる（`05`のE）→ 炎上耐性＆信頼。

## 5. 税務
- 副業所得は**確定申告**（雑所得または事業所得）。売上・経費（AI/Vercel/ドメイン等）を記帳。
- 稼働そのものの収支と、情報事業の収支は分けて管理。

## 6. 個人情報・データ
- LINE・稼働ログSaaSで個人情報/稼働データを扱う → **プライバシーポリシー掲示・SSL・最小収集**。
- ログSaaSは「ユーザーのデータを人質にする」設計ゆえ、**取扱いの信頼性が事業の生命線**。

## リスク登録簿（monitor）
| リスク | 影響 | 対策 |
|---|---|---|
| 決済停止/アカBAN | 収益断絶 | 経路分散・規約順守・誇大表現ゼロ |
| 集客が伸びない | ローンチ不発 | 90日で楔/チャネル見直し（`07`撤退基準） |
| 実践値データ不足 | 層2が成立しない | 自分の稼働ログを最優先で蓄積 |
| 誇大表現での通報/指導 | 信頼毀損・法務 | 景表法セルフチェックを全コピーに |
| 本業との両立崩れ | 継続不能 | 週14h上限を守る・自動化優先 |
