# 無料ツール仕様（集客エンジンのMVP）

Claude Code + Next.js + Vercel Pro で実装する前提。**まずは"データ不要で成立する計算ツール"から**（データ収集リスクを後回しにできる）。

## MVP（v1）: 時給期待値カリキュレーター
**ゴール**: 「今から○時間打てる。この台の期待値は時給いくら？打つべき？」を即答。

- 入力: 現在ゲーム数 / 天井・ゾーン / 1000円あたり回転数 or 平均G/時 / 打てる残り時間
- 出力: **期待値（円）／時給期待値（円/h）／推奨アクション（打つ・様子見・やめ）**
- 特徴: 兼業視点＝「時給」で判断。競合の期待値表にはこの一手間がない。
- 技術: 完全クライアントサイド（サーバー・DB・外部データ不要）。静的計算のみ＝**法的にもデータ的にも最も安全**。
- CTA: 「機種別の狙い目・実践値は LINE で配信」→ リスト獲得。

## v2: 機種別狙い目まとめ（軽DB）
- 主要スマスロの天井/ゾーン/やめどきを一覧化（自分で埋める。最初は10〜20機種）。
- 更新は自分の稼働＋公開情報ベース。**「絶対」表現を使わない**（`08`）。

## v3: 稼働ログ（乗り換えコストを作る本命機能）
- 差枚・投資・回収・時給・機種・店を記録 → 月次で「自分の実践値・時給推移」を可視化。
- ログイン必要（ここで初めて認証/DB）。使うほどデータが貯まり離脱しにくくなる＝`03`の防御。
- 有料メンバー限定の高度分析（設定示唆の集計等）への入口。

## 実装メモ
- スタック: Next.js(App Router) / Vercel / v3で Supabase or Vercel Postgres + Auth。
- 計測: Vercel Analytics + 簡易イベント（ツール利用→LINE遷移率を見る）。
- **顔出し不要**。ブランドはテキスト＋ロゴのみで成立。
- 決済は層2から（Stripe or note/YouTubeメンバーシップ）。ギャンブル隣接の決済可否を事前確認（`08`）。
