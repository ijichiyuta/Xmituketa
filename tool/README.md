# 時給ハイエナ計算機（MVP）

兼業ハイエナ（平日2hしか打てない会社員）向けの **時給期待値カリキュレーター**。
「残り時間で完走できるか」「1時間あたりいくらの期待値になるか」を出して、
**打つ / 様子見 / やめ** を即判断するための、完全クライアントサイドのツールです。

DB・認証・外部API・サーバー処理は一切ありません。入力値はブラウザの `localStorage` にのみ保存されます。

---

## 注意（必ずお読みください）

- 本ツールは **学習・期待値管理を目的** としたものです。**勝敗や収支を保証するものではありません。**
- 表示される期待値・時給は **長期・試行回数前提の理論値** であり、短期の結果を保証しません。
- **機種データは同梱していません。** 天井・期待値は各自が公開期待値表等で確認して手入力してください。入力値の正確性・結果について責任を負いません。
- **20歳未満の方はご利用いただけません。**

## 計算式

| 項目 | 式 |
|---|---|
| 残りゲーム数 | `天井G − 現在G` |
| 所要時間（分） | `残りG ÷ 消化速度(G/h) × 60 ＋ 当選後の消化時間(分)` |
| 時給期待値（円/h） | `期待値(円) ÷ (所要時間 ÷ 60)` |
| 時間切れ判定 | `所要時間 > 打てる残り時間` |

### 推奨アクションの決定

1. **時間切れ**（所要時間 > 残り時間）→ **やめ**（赤）
2. **時給期待値 ≥ 判定閾値** → **打つ**（緑）
3. それ以外 → **様子見**（黄）

### 計算例（受入基準）

- 入力: 現在 500G / 天井 1000G / 800 G/h / 当選後 15分 / 期待値 ¥3,000 / 残り 120分 / 閾値 ¥2,000
- 残りG = 500
- 所要時間 = 500 ÷ 800 × 60 + 15 = **52.5分**
- 時給期待値 = 3000 ÷ (52.5 ÷ 60) ≈ **¥3,429/h**
- 52.5分 ≤ 120分（時間内）かつ 3429 ≥ 2000 → 判定 **打つ**

計算ロジックは `src/lib/calc.ts` に純関数として分離しています（`src/lib/ev.ts` はその再エクスポート＋機種プリセット）。

## ローカル起動

```bash
npm install
npm run dev
```

ブラウザで http://localhost:3000 を開きます。入力を変えるとリアルタイムで再計算されます。

### そのほかのコマンド

```bash
npm run build   # 本番ビルド
npm test        # calc.ts のユニットテスト（vitest）
npm run lint    # ESLint
```

## 環境変数

| 変数 | 用途 | 未設定時 |
|---|---|---|
| `NEXT_PUBLIC_LINE_URL` | フッターのLINE登録CTAのリンク先 | `#`（ボタンは表示されるがリンクは無効） |

ローカルで設定する場合は `tool/.env.local` に記載します。

```
NEXT_PUBLIC_LINE_URL=https://lin.ee/xxxxxxx
```

## Vercel デプロイ手順

このアプリはリポジトリ直下ではなく `tool/` サブディレクトリにあります。Vercel では **Root Directory** の指定が必要です。

1. Vercel でリポジトリをインポート
2. **Settings → General → Root Directory** に `tool` を指定
3. Framework Preset は **Next.js**（自動検出）
4. **Environment Variables** に `NEXT_PUBLIC_LINE_URL` を設定（任意）
5. Deploy

ビルドコマンド・出力ディレクトリは Next.js の既定のままで動作します。
